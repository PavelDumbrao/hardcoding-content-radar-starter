# Проект

## Название

Content Radar AI — стартовый проект Hardcoding PRO

## Что мы создаём

Сервис контент-разведки с интерфейсом-чатом. Ты пишешь запрос обычным текстом,
например: «Что сейчас залетает в вайб-кодинге?», а сервис сам ищет контент на
площадках, считает метрики роста и показывает разбор: почему это сработало и как
адаптировать механику под себя.

Это не «ещё один чат с ИИ». Здесь есть жёсткое разделение:

- **ИИ понимает запрос** и объясняет смысл: что залетает, почему, какие идеи из этого сделать.
- **Обычный код считает цифры**: просмотры, скорость роста, скорость ускорения, outlier.
- **ИИ никогда не придумывает числа.** Любая цифра приходит из инструмента и имеет дату замера.

## Для кого

Для авторов и предпринимателей, которые делают контент про AI, вайб-кодинг,
автоматизации и бизнес — и хотят опираться на данные, а не на ощущения.

В учебном контексте: для участников Hardcoding PRO, которые учатся собирать
продукт с ИИ-агентом, Docker и деплоем.

## Главный результат

Работающий сервис, открытый в браузере:

1. Пишешь запрос в чат.
2. Агент сам вызывает инструменты и идёт в источники.
3. На экране появляется ответ с найденным контентом, метриками, ссылками и временем замера.
4. Отдельно видно, какие шаги сделал агент и на какие данные он опирался.

## Ограничения

- Нельзя выдумывать метрики, даты и ссылки. Нет данных — сервис честно говорит об этом.
- Нельзя коммитить `.env`, ключи, токены и пароли.
- Нельзя ломать `main`: заметные изменения только через отдельную ветку и Pull Request.
- Тяжёлый анализ (расшифровки, разбор видео по кадрам) не делается для всего найденного:
  сначала фильтр по цифрам, и только лучшие кандидаты идут в дорогой анализ.

## Стек

| Слой | Технология |
|---|---|
| Интерфейс | HTML + CSS + JavaScript (чат с рендером Markdown) |
| API | Python 3.12, FastAPI |
| Агент | PydanticAI (типизированные инструменты) |
| База | PostgreSQL 16 + pgvector |
| Запуск | Docker Compose |
| Источники | YouTube Data API, VK API, Instagram через Apify |
